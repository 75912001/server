# Markdown 常用语法说明

Markdown 文件通常使用 `.md` 作为扩展名。本文整理常用语法及示例, 可作为日常编写文档时的速查手册。

## 1. 标题

标题使用 `#` 表示, `#` 的数量代表标题级别。`#` 后需要保留一个空格。

```md
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

## 2. 文本样式

```md
**粗体文本**
*斜体文本*
***粗斜体文本***
~~删除线文本~~
`行内代码`
```

显示效果:

**粗体文本**

*斜体文本*

***粗斜体文本***

~~删除线文本~~

`行内代码`

## 3. 段落与换行

不同段落之间保留一个空行。

如果需要在同一段中强制换行, 可以在行尾添加两个空格后再换行, 也可以直接使用 HTML 的 `<br>` 标签。

```md
第一段内容。

第二段内容。

第一行。␠␠
第二行。

第三行。<br>
第四行。
```

上例中的 `␠␠` 仅用于展示空格位置, 实际编写时应替换为两个普通空格。

## 4. 无序列表

无序列表可以使用 `-`、`*` 或 `+`, 建议统一使用 `-`。

```md
- 苹果
- 香蕉
- 橙子
```

嵌套列表需要缩进:

```md
- 水果
  - 苹果
  - 香蕉
- 蔬菜
  - 白菜
  - 萝卜
```

## 5. 有序列表

```md
1. 第一步
2. 第二步
3. 第三步
```

## 6. 可选项与勾选框

任务列表使用 `- [ ]` 表示未勾选项, 使用 `- [x]` 表示已勾选项。

```md
- [ ] 未完成选项
- [x] 已完成选项
- [ ] 需要确认
  - [x] 子任务已完成
  - [ ] 子任务未完成
```

显示效果:

- [ ] 未完成选项
- [x] 已完成选项
- [ ] 需要确认
  - [x] 子任务已完成
  - [ ] 子任务未完成

注意: 勾选框能否直接点击取决于 Markdown 查看器。普通 Markdown 文件中的勾选框通常只是状态展示, 修改状态时需要编辑 `[ ]` 或 `[x]`。

## 7. 表格

使用竖线 `|` 分隔列, 使用短横线 `-` 分隔表头和内容。

```md
| 名称 | 类型 | 是否启用 | 说明 |
| --- | --- | --- | --- |
| 登录服务 | 服务 | 是 | 处理用户登录 |
| 网关服务 | 服务 | 否 | 转发客户端请求 |
```

显示效果:

| 名称 | 类型 | 是否启用 | 说明 |
| --- | --- | --- | --- |
| 登录服务 | 服务 | 是 | 处理用户登录 |
| 网关服务 | 服务 | 否 | 转发客户端请求 |

### 表格对齐

在分隔行中使用冒号 `:` 设置对齐方式。

```md
| 左对齐 | 居中对齐 | 右对齐 |
| :--- | :---: | ---: |
| 内容 | 内容 | 100 |
```

| 左对齐 | 居中对齐 | 右对齐 |
| :--- | :---: | ---: |
| 内容 | 内容 | 100 |

## 8. 链接

```md
[链接显示名称](https://example.com)

[跳转到标题章节](#1-标题)

<https://example.com>
```

说明:

- 普通链接由方括号中的名称和圆括号中的地址组成。
- 章节链接以 `#` 开头, 具体规则可能因 Markdown 查看器而略有不同。
- 直接使用尖括号包裹网址可以生成自动链接。

## 9. 图片

图片语法与链接类似, 但最前面需要添加 `!`。

```md
![图片说明](./images/example.png)

![网络图片](https://example.com/example.png)
```

建议优先使用相对路径引用项目内图片, 避免写入本机绝对路径。

## 10. 引用

引用内容使用 `>` 开头。

```md
> 这是一段引用内容。
>
> 引用中也可以包含多个段落。
```

嵌套引用:

```md
> 一级引用
>
>> 二级引用
```

## 11. 代码

### 行内代码

使用一对反引号包裹简短的命令、字段名或代码。

```md
执行 `go test ./...` 运行全部 Go 测试。
```

### 多行代码块

使用三个反引号包裹代码, 并在开头标明语言以启用语法高亮。

````md
```go
package main

import "fmt"

func main() {
	fmt.Println("hello")
}
```
````

常见语言标识包括 `go`、`bash`、`json`、`yaml`、`sql`、`javascript` 和 `text`。

## 12. 分隔线

单独一行输入三个或更多短横线:

```md
---
```

显示效果:

---

## 13. 转义特殊字符

如果需要显示 Markdown 特殊字符本身, 可以在字符前添加反斜杠 `\`。

```md
\# 这不是标题
\*这不是斜体\*
\[这不是链接\]
```

常见特殊字符包括:

```text
\ ` * _ { } [ ] ( ) # + - . ! |
```

## 14. 折叠内容

折叠内容属于 HTML 扩展语法, 常见 Markdown 查看器通常支持。

```html
<details>
<summary>点击查看详细内容</summary>

这里是折叠后的详细内容。

</details>
```

显示效果:

<details>
<summary>点击查看详细内容</summary>

这里是折叠后的详细内容。

</details>

## 15. 注意事项

- 标记符号后通常需要保留一个空格, 例如 `# 标题`、`- 列表项`。
- 段落、列表、表格和代码块之间建议保留空行, 便于阅读和兼容不同查看器。
- 项目内链接和图片建议使用相对路径。
- 不同 Markdown 查看器支持的扩展语法可能不同, 例如可点击勾选框、折叠内容和流程图。
- 文档中的代码块应标明语言, 便于阅读和语法高亮。
