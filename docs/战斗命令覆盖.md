# 8.5战斗命令覆盖矩阵

更新时间: 2026-07-15.

## 1. 基准和口径

命令定义以`gmsv/include/battle.h`的`BATTLE_COM`枚举为准, 条件编译状态以`version.h`和`correct_bug.h`为准. 当前枚举中的全部条件宏均已定义, 因此有效命令为139个; `BATTLE_COM_END=2111`只作为枚举结束哨兵, 不计入命令数.

执行入口扫描范围与`gmsv/battle/makefile`一致, 只包含8个实际编译单元. `case`列只统计当前启用分支; “非case引用”用于定位命令生成、改写、比较和AI前置处理, 不能单独证明语义已经审计完成.

旧客户端入口只用于说明8.5命令来源. 现代生产协议仍按已确认方案统一为技能动作, 不移植H/G/N/E/T/S/W/J/I/P字符串协议.

## 2. 汇总

| 项目 | 数量 |
|---|---:|
| 当前有效命令 | 139 |
| 有执行`case`的唯一命令 | 126 |
| 非 switch 有效命令 | 13 |
| 枚举结束哨兵 | `BATTLE_COM_END=2111` |

一期最小基础命令包括攻击、防御、逃离和宠物待机; 当前PVE还按用户逐项确认开放了配置型宠物特殊技能. 合击由服务端派生. 覆盖矩阵中的“当前归属”以实际生产实现为准, 未开发命令继续归入下一期或旧服内部兼容范围.
